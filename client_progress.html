3D Gaussian Avatar

Train a photorealistic animatable 3D head avatar using ELITE (CVPR 2026)

Complete
▾

Input

  • Matted video frames (512×512)
  • FLAME tracking params from Stage 2
  • Pre-trained ELITE prior model (4.9GB)

Output

  • IMG_9625_avatar.ply — 3D Gaussian avatar
  • 262,144 Gaussians representing the head
  • Viewable in Blender / SuperSplat
Steps
Prior model personalization (Stage 1) Fine-tuned the ELITE AI prior model to this person's face shape and appearance — 21 epochs
Synthetic expression generation Generated 787 synthetic renders of the face in random expressions (smile, frown, open mouth etc.)
Joint fine-tuning (Stage 2) Trained avatar on both real frames + synthetic expressions — 51 epochs, val PSNR 26.4
PLY export Exported 262,144 Gaussians as standard 3DGS PLY file

Output location

elite/outputs/IMG_9625/
├── IMG_9625_avatar.ply3D Gaussian Splat — open in Blender or SuperSplat
├── st1/checkpoints/st1_final.pthStage 1 model weights
└── st2/checkpoints/st2_final.pthFinal avatar model weights
💡 What is a 3D Gaussian Splat? The avatar is represented as 262,144 tiny 3D ellipsoids (Gaussians) instead of a traditional polygon mesh. This enables photorealistic rendering from any viewpoint and smooth animation of facial expressions.
